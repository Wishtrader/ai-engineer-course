# cost-router: интерактивный курс

Учебная платформа по проекту [`cost-router`](https://github.com/Wishtrader/cost-router): 12 шагов
(9 разборов кода + 3 практических), чек-листы, задания с командами, экзамены по каждому шагу, поиск,
заметки, трекер прогресса и план из 7 фаз под трек B (AI Product Engineer).

**Открыть:** https://wishtrader.github.io/ai-engineer-course/

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | оболочка: боковая навигация, шапка с прогрессом, панели |
| `course.js` | **лекционный контент**: шаги 1–9, блоки, чек-листы, задания, план фаз |
| `practice.js` | практика по фазам 1–3 (шаги 10–12): шлюз, память/RAG, evals |
| `exams.js` | вопросы экзаменов по шагам (3 на шаг) |
| `app.js` | рендер, подсветка кода, прогресс, экзамен, поиск, заметки, напоминания |
| `styles.css` | тёмная тема, типографика, адаптив |

Зависимостей нет: чистый HTML/CSS/JS, всё работает как статический сайт на GitHub Pages.
Контент отделён от логики, поэтому курс расширяется правкой одного файла.

## Как обновлять

Изменения приходят коммитом в `main`; GitHub Pages пересобирает сайт автоматически (обычно меньше минуты).
На телефоне достаточно обновить страницу — прогресс в `localStorage` не сбрасывается при обновлении кода.

```bash
git pull            # забрать новые шаги
# открыть страницу заново — новый контент на месте
```

Если хочется локально:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Прогресс

- хранится в `localStorage` браузера под ключом `crc:v1` — **привязан к устройству и браузеру**;
- кнопка «Данные прогресса» → скачать/импортировать `.json`, сброс;
- очистка кэша сайта удаляет прогресс, поэтому экспорт перед чисткой — обязателен.

## Возможности

- **Подсветка синтаксиса** в блоках кода — свой токенизатор без зависимостей: Python, bash, JSON; кнопка copy на каждом блоке.
- **Экзамены** — 3 вопроса на каждый из 12 шагов (36 всего), разбор каждого ответа, счёт в сайдбаре и в шапке шага. Раздел «Экзамены» в сайдбаре.
- **Поиск** — `Ctrl/⌘ + K` или `/`; ищет по тексту, коду, пунктам, заданиям и вопросам; переход сразу к нужному блоку с подсветкой.
- **Заметки** — кнопка ✎ у любого пункта чек-листа и задания; хранятся вместе с прогрессом, видны списком в «Данных прогресса», попадают в экспорт.
- **Прогресс** — 87 пунктов, кольцо в сайдбаре, счётчики по шагам, кнопка «Продолжить».

## Напоминания

1. **Внутри приложения:** «Напоминания» → разрешить уведомления → включить и задать время.
   Срабатывает, пока вкладка открыта (ограничение браузера: статический сайт без service worker
   не может будить себя в фоне).
2. **По-настоящему, вне браузера:** «Скачать .ics» — ежедневное событие с напоминанием за 5 минут.
   Импортируется в Google Calendar, iOS, календарь Telegram-бота.
3. Плюс баннер «прошло N дней» на главной, если забросили больше двух дней.

## Структура данных (для правки `course.js`)

```js
window.COURSE = {
  meta: { title, subtitle, updated, repo },
  steps: [{
    id, n, title, summary,
    blocks: [
      { type: "h2" | "p" | "ul" | "ol" | "note" | "code" | "checks", ... },
      { type: "code", caption: "…", lines: ["строка", "строка"] },
      { type: "note", kind: "warn" | "tip", title: "…", text: "…" },
      { type: "checks", items: [{ id: "уникальный-id", text: "…" }] }
    ],
    tasks: [{ id, title, why, cmd }]
  }],
  plan: { title, lede, phases: [{ n, title, what, closes: [], metric, todo: [{ id, text }] }] }
};

// exams.js
window.EXAMS = { 2: [{ q: "вопрос", options: ["…", "…"], a: 1, why: "пояснение" }] };
// practice.js дописывает шаги: COURSE.steps.push({ id, n, title, summary, blocks, tasks })
```

Правила: `id` уникален по всему курсу (он ключ прогресса — менять нельзя, иначе пункт «сбросится»);
в `code` не нужны `\n` — это массив строк; `text` допускает инлайн-HTML (`<code>`, `<strong>`).
